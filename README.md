# ChatBot Valcapelli v2

Chatbot de bem-estar e autoconhecimento com foco em **Cromoterapia** e **Metafísica da Saúde**.

## 🚀 Stack Tecnológica

- **React 18** - Framework UI moderno
- **Vite** - Build tool rápido
- **TailwindCSS** - Estilização utilitária
- **Lucide React** - Ícones modernos

## 📦 Instalação

```bash
# Instalar dependências
npm install

# Criar arquivo de ambiente
cp .env.example .env

# Editar .env com suas credenciais
# VITE_API_KEY=sua_api_key
```

## 🏃 Executar

```bash
# Desenvolvimento
npm run dev

# Build para produção
npm run build

# Preview do build
npm run preview
```

## ✨ Funcionalidades

- **Dois temas distintos**: Cromoterapia e Metafísica da Saúde
- **Chat interativo** com integração LangGraph
- **Formulário de registro** opcional (nome, telefone, email)
- **Informações de contato** completas
- **Design responsivo** e moderno
- **Animações suaves** e gradientes coloridos

## 🎨 Temas

### Cromoterapia
Gradiente roxo → rosa → laranja, focado em como as cores influenciam saúde e bem-estar.

### Metafísica da Saúde
Gradiente teal → azul → índigo, focado nas causas emocionais por trás dos sintomas físicos.
